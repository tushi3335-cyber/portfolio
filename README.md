# Tushar Ramteke — Portfolio

A responsive, single-page React portfolio created from Tushar’s CV. It includes a profile, career history, filterable experience, skills, education, contact links, and the original résumé PDF.

## Run locally

Install Node.js (LTS), then open this folder in a terminal and run:

```sh
npm install
npm run dev
```

To make a production build, run `npm run build`. Vite writes the output to `dist/`; `npm run preview` serves that build locally.

## Project files

- `src/App.jsx` — page content and interactive experience filters.
- `src/styles.css` — responsive layout and visual design.
- `resume.pdf` — the original CV, linked from the navigation.

Job dates aren’t listed in the source CV, so the portfolio doesn’t invent any.
